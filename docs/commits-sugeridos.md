# Secuencia de commits

El historial local se organizó en diez cambios identificables:
1. Estructura inicial y documentación del proyecto.
2. Maquetación HTML de la aplicación web.
3. Estilos CSS y diseño adaptable.
4. Lógica del contador y manipulación del DOM.
5. Registro de clics con marca de tiempo.
6. Función para restar likes y validación del mínimo.
7. Función para reiniciar contador e historial.
8. Aplicación móvil con componentes React Native y estado.
9. Tema dinámico al superar diez likes y ajustes de interfaz móvil.
10. Bitácora, cuadro comparativo y plan de pruebas.

Los commits de este paquete son locales. Para publicarlos en GitHub se debe configurar la URL del repositorio remoto y ejecutar `git push -u origin main`.
